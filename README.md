# LLM Praxis

Lessons on AI and Claude Code, from the plain words to real work on real
projects. Each part builds on the part before it.

| Part | Directory | Topic |
|------|-----------|-------|
| 1 | `part-1-slides/` | Slides: AI from scratch, a Claude Code reference and Claude Code 201 |
| 2 | `part-2-playground/` | A playground for one repository: Claude Code builds and ships a small app on a local GitLab, with pipelines and two servers |
| 3 | | A playground for a workspace with several repositories and a deployment to AWS |
| 4 | | The same tasks in other AI harnesses, compared |

New to AI? Open these in order:

1. `part-1-slides/ai-basics.html`: the plain words of AI, with interactive parts.
2. `part-2-playground/slides/index.html`: Claude Code 101, hands-on. To run it,
   start with `part-2-playground/README.md`.

`part-1-slides/claude-code-reference.html` is a reference for Claude Code, to
read at any time. Part 1 also has the text of the slides as Markdown.
