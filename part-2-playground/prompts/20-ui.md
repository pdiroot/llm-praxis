## Goal
Add a web UI for the whoami page, in a new branch. Use the frontend-design skill. Run the app locally and check it in the browser.

## Limits
- A browser (`Accept: text/html`) gets the page at `/`. curl and `?format=json` keep their answers.
- Standard library only. Embed the page in the binary.
- Add one line to CLAUDE.md: check each UI change locally with Claude in Chrome before the merge request, and on test after the merge.

## Check
- Use Claude in Chrome to open the local page and read it on screen.
- Run `go fmt ./...`, `go vet ./...` and `go test ./...`. All pass.

## Context
- The page shows the host name, the IP addresses and the headers of the visitor, in a clear layout.
